# OCR 테스트 이미지
`sample_01.png`: 팀원끼리 한 사용자 설정 게임에서 채팅창을 캡처해 넣고, `fixtures/ocr/expected.jsonl`의 줄 내용을 실제 이미지에 맞게 고칩니다.
(이미지는 500KB 이하로. 큰 원본은 구글 드라이브)

OPEN-03 측정용 실제 롤 채팅 캡처는 10~20장을 준비하고 실제 닉네임을 가린다. 원본·가린 이미지·줄별 정답은 `.clean-chat/ocr-benchmark/` 같은 Git 제외 로컬 경로에 보관하고 커밋하지 않는다. 합성 이미지의 가상 닉네임에는 ADR-0020을 적용한다. 합성 데이터와 실제 게임 캡처의 결과는 구분해 기록한다.

측정 기준과 재현 명령은 `src/clean_chat/modules/ocr/BENCHMARK.md`를 참고한다. 사용자 제공 `synth_v1.zip`은 합성 데이터이며 실제 롤 캡처를 대신하는 최종 평가 자료가 아니다.
