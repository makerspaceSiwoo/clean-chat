# 라벨링 가이드 (전원)

> 목표: 1인당 **100문장 이상**. 정답이 애매하면 "메모"에 이유를 적고, 금요일에 팀이 함께 정합니다.
> **실제 유저의 채팅이나 닉네임은 쓰지 않습니다.** 롤에서 볼 법한 문장을 직접 지어서 씁니다.

## 시트 열 (CSV 열 이름)

| 열 | 값 | 예 |
|---|---|---|
| `text` | 채팅 본문 | `야 정글 ㅂㅅ아 용 먼저 치라고` |
| `level` | 0 / 1 / 2 / 3 | `2` |
| `harm_types` | `profanity`, `family_insult`, `sexual_harassment`, `blame`, `instigation` 중 해당하는 것을 `|`로 연결 (없으면 빈칸) | `profanity|blame` |
| `has_feedback` | 0 / 1 | `1` |
| `feedback` | 피드백만 다듬은 문장 (`has_feedback=1`일 때) | `용 먼저 치자` |
| `target` | 대상: `me`(나) / `team`(팀원) / `enemy`(상대) / `none`(대상 없음) / `unknown` | `team` |
| `writer` | 작성자 이니셜 | `C` |
| `note` | 애매한 이유 | |

## 등급 판단 순서
1. **특정한 사람을 향하는가?** 아니면 L0 또는 L1 (예: "아 ㅅㅂ 내가 실수함" → L1)
2. **가족, 성적인 내용, 협박이 있는가?** 있으면 L3
3. **욕설, 비난, 팀원 몰이가 있는가?** 있으면 L2
4. 그 밖의 경우는 L0. 장난이 분명한 경우(친구 사이 "ㅋㅋ 미친놈 잘하네")는 L0 또는 L1

## 피드백 판단
- 게임에서 **할 수 있는 행동**이 들어 있으면 피드백입니다: 용, 바론, 시야, 합류, 귀환, 라인 관리, 한타, 스킬 사용 등
- "왜 그것도 못 함" → 행동이 없으므로 피드백 아님
- "정글 탑 좀 와 ㅂㅅ아" → 피드백 있음 → `feedback`: "정글 탑 와줄 수 있어?"

## 골고루 만들기 (비율 목표)
| 종류 | 비율 |
|---|---|
| L0 정상 (콜, 핑, 잡담) | 35% |
| L1 경미 | 15% |
| L2 악성 (그중 절반은 피드백 포함) | 35% |
| L3 법적 대응 후보 | 15% |
| **우회 표현**(`시1발`, `tlqkf`, `ㅅ ㅂ`)이 들어간 문장 | 전체의 30% 이상 |

## 헷갈리는 예
| 문장 | level | 이유 |
|---|---|---|
| `미드 갱 ㄱㄱ` | 0 | 콜 |
| `아 ㅈㄴ 아프네` | 1 | 대상 없음 |
| `원딜 개못하네 트롤이냐` | 2 | 특정인 비난, 피드백 없음 |
| `다들 정글 탓인 거 알지? 정글 신고 ㄱ` | 2 | 정치질 |
| `서폿 와드 좀 박아 ㅂㅅ아` | 2 | 피드백 있음 → "시야 좀 잡아 주세요" |
| (가족을 모욕하는 표현) | 3 | 패드립 |
