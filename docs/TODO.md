## 신규 채팅 판독 (`core/pipeline.py` `LineDedup`)

현재 방식: 이전 화면 줄 목록의 끝과 이번 화면의 앞이 **글자 그대로** 가장 길게 겹치는 구간을 찾고, 그 뒤 줄만 새 채팅으로 처리한다.
- 글자를 하나도 못 읽은 화면(채팅창 숨김)은 비교 기준을 바꾸지 않는다.
- 이전 화면과 한 줄도 겹치지 않는 화면은 OCR 오작동으로 보고 버린다. 같은 화면이 3번 연속 나오면 받아들인다.
- report 는 중복 제거를 하지 않는다 (같은 채팅을 여러 번 친 것도 각각 기록).

- [ ] **OCR 이 같은 줄을 프레임마다 다르게 읽으면** (`ㅂㅅ`↔`ㅂ시`, `l`↔`1`, 끝 글자 잘림) 겹침이 끊겨
      이미 처리한 줄을 새 채팅으로 다시 처리하거나, 겹침이 0이 되어 새 화면을 버린다.
      후보: 헤더/본문 분리 + 유사도 비교 + 순서 유지 정렬. 기준값은 실제 게임 캡처 샘플로 정한다.
- [ ] **보이는 줄이 전부 같은 문장일 때** (예: 채팅창 전체가 `ㅋㅋㅋㅋ`) 한 줄이 더 올라와도 화면이 그대로라
      새 채팅을 놓친다. 채팅 타임스탬프(게임 설정) 또는 채팅창 스크롤 위치(픽셀)로 구분할 방법이 필요하다.
- [ ] **같은 잡음이 3프레임 연속 나오면** 연속성 검사를 통과해 비교 기준이 잡음으로 바뀐다. 실제 게임에서 빈도를 확인한다.
