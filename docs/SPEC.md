# LoL Guard — 제품 명세 (SPEC)

> 이 문서는 "무엇을, 왜" 만드는지에 대한 **유일한 기준**입니다.
> 바꾸려면 리드에게 PR을 올리고, 바뀐 이유는 `docs/DECISIONS.md`에 기록합니다.
> 버전: v0.2 (2026-11-12, 1차 모임 이후 변경 반영)

---

## 1. 한 줄 목표

**리그 오브 레전드 게임 중, 나에게 오는 악성 채팅은 보이지 않게 숨기고(필요하면 피드백만 남기고), 증거는 신고·고소용으로 정리하며, 내가 치는 채팅도 비난 없이 나가도록 돕는 Windows 데스크톱 앱.**

- 대상 게임: 리그 오브 레전드 **하나만** (한국 서버, 한국어 채팅)
- 기간: 발표 전 주말 3번 (마지막 주말은 데모 완성과 발표 자료 제작)
- 실행 환경: **실제 앱은 Windows**, 개발은 Mac에서도 가능(설치, 모듈 단독 실행, mock 전체 실행, UI 화면) — ADR-0012
- 성격: 해커톤형 데모. 유저 테스트 없음. **페인 포인트 해결이 보이는 것**이 목표

## 2. 페인 포인트

1. 게임 중 욕설·패드립·성희롱을 그대로 보게 되어 멘탈이 무너진다.
2. 라이엇의 기본 필터는 우회 비속어(`시1발`, `tlqkf`, `ㅅ ㅂ`)를 잘 못 잡는다.
3. 전체 뮤트를 하면 쓸모 있는 정보(콜, 피드백)까지 같이 잃는다.
4. 신고와 고소는 증거 정리가 귀찮아서 결국 안 하게 된다.
5. 나도 화가 나면 비난을 섞어서 치게 된다.

## 3. 화면 구성 (UI 2개)

### 3-1. 클라이언트 UI (게임 밖 창, PySide6)
- 앱 실행, 종료, **감시 시작과 중지**
- **사용법 안내**: 롤 설정(테두리 없는 창 모드, 채팅 색과 배경 설정), 오버레이 위치 맞추기
- **처리 내역**: 감지된 채팅 목록(시간, 화자, 원문, 등급, 처리 결과)
  - 신고 내용 **복사** 버튼
  - 고소장 초안 **PDF 다운로드** 버튼
- 설정: 내 소환사명, 등급별 처리 방식(데모용 고정값)

### 3-2. 오버레이 UI (게임 위 창, PySide6)
- 게임 채팅창 위치에 맞춰 **크기와 위치를 사용자가 조정**합니다(보정 모드).
- 게임 채팅창을 **가리고**, 필터를 거친 채팅과 핑을 보여 줍니다.
- **내 채팅 입력칸**: 입력하면 필터를 거친 결과를 클립보드에 복사합니다. 사용자는 게임 채팅창에 직접 붙여넣어 전송합니다(가상 키보드 입력을 쓰지 않음, ADR-0006).
- 오버레이 자체는 **화면 캡처에서 제외**되어야 합니다. 그래야 OCR이 오버레이가 아니라 밑에 있는 게임 채팅을 읽습니다(ADR-0003).

## 4. 악성 채팅 분류 체계

### 4-1. 유해 유형 (`HarmType`, 여러 개 가능)
| 코드 | 한국어 | 예시 (순화) |
|---|---|---|
| `profanity` | 욕설 | ㅅㅂ, 시1발, tlqkf |
| `family_insult` | 패드립 | 가족을 모욕하는 표현 |
| `sexual_harassment` | 성희롱 | 성적인 비하나 희롱 |
| `blame` | 비난 | "미드 개못하네", "트롤이냐" |
| `instigation` | 정치질 | "다들 정글 탓인 거 알지? 정글 신고 ㄱ" (팀원 몰이) |

### 4-2. 수준 (`Level`)
| 등급 | 이름 | 기준 |
|---|---|---|
| **L0** | 정상 | 일반 채팅, 핑, 스펠 체크, 콜 |
| **L1** | 경미 | 특정 대상이 없는 혼잣말 비속어("아 ㅅㅂ 내가 실수함"), 친근한 장난 |
| **L2** | 악성 | 특정인을 향한 비난, 욕설, 정치질 |
| **L3** | 법적 대응 후보 | 패드립, 성희롱, 심한 모욕이나 명예훼손, 협박처럼 **특정인을 향한** 고강도 표현 |

### 4-3. 피드백 포함 여부 (`has_feedback`)
L2 이상이면서 게임 진행에 대한 지적이나 방향 제시가 섞여 있으면 `true`입니다.
- 예: "야 ㅂㅅ아 용 먼저 치라고 몇 번 말해" → 피드백: "용 먼저 치자"

## 5. 처리 규칙 (정책표)

> **분류 모델은 "분류"만 합니다.** 실제 처리는 `policy` 모듈이 **누가 쓴 채팅인지(타 유저 / 나)** 에 따라 정합니다.

### 5-1. 타 유저 채팅
| 조건 | 화면 표시 | 기록과 신고 |
|---|---|---|
| L0 | 그대로 표시 | 없음 |
| L1 | 비속어만 `***`로 가리고 표시 | 없음 *(가정, OPEN-07)* |
| L2 + 피드백 있음 | **AI가 비난을 지운 피드백 문장만** 표시 | 원문 → 신고 목록 |
| L2 + 피드백 없음 | **표시 안 함** | 닉네임과 원문 → 신고 목록 |
| L3 | **표시 안 함** (피드백이 있으면 피드백만) | 신고 목록 + **고소장 초안 후보** |

### 5-2. 내 채팅
| 조건 | 결과 |
|---|---|
| L0 | 그대로 클립보드에 복사 |
| L1 | 비속어만 가린 문장을 복사 |
| L2 + 피드백 있음 | **비난을 지운 피드백 문장**을 복사 |
| L2 + 피드백 없음, L3 | **전송 차단** + 안내 문구 ("이 문장은 보낼 수 없어요") |

### 5-3. 신고와 고소장
- **신고**: 데모 단계에서는 **자동 신고를 하지 않습니다.** 신고 문구(닉네임, 시간, 원문, 유형)를 만들어 주고, 사용자가 복사해서 게임 안 또는 게임 후 신고에 붙여넣습니다(ADR-0007).
- **고소장**: L3 기록을 묶어 **정해진 양식에 맞춘 초안 PDF**를 만듭니다. 실제 제출용이 아닌 **초안**이며 "법률 자문이 아님" 문구를 넣습니다(ADR-0008).

## 6. 모듈 구성

모듈별 역할과 입출력 명세는 **`docs/MODULES.md`**, 구조는 **`docs/ARCHITECTURE.md`**, 데이터 형식은 **`docs/CONTRACTS.md`** 를 기준으로 합니다.

```
[🪟 화면 캡처] → ocr → parse → normalize → classify → (L2↑ & 피드백) rewrite → policy → UI(클라이언트/오버레이)
                                                                                   └→ report / complaint
```

### AI가 필요한 지점 (4개)

| # | 이름 | 입력 → 출력 | 모듈 |
|---|---|---|---|
| A1 | **OCR** | 채팅창 영역 이미지 → 텍스트 줄 | `capture` |
| A2 | **분류** | 정리된 문장 → 유해 유형, 등급, 피드백 포함 여부 | `classify` |
| A3 | **피드백 추출 + 문장 다듬기** | 악성 문장 → 피드백 부분만 → 자연스러운 게임 용어 문장 | `rewrite` |
| A4 | **신고 문구 / 고소장 작성** | 기록 묶음 → 신고 텍스트 / 고소장 PDF | `report` |

- A2는 **모든 채팅**에 실행되므로 빠른 소형 모델(KcBERT/KcELECTRA 계열)을 씁니다.
- A3과 A4는 **악성으로 분류된 일부 채팅에만** 실행되므로 생성형 모델(LLM)을 씁니다(ADR-0005).

## 7. 데모 시나리오 (발표 3분)

1. 클라이언트 실행 → 사용법 안내 → 오버레이 위치 맞추기
2. 연습 게임 또는 사용자 설정 게임에서 팀원(우리 팀원)이 미리 정한 대본대로 채팅
3. 오버레이에서 정상 채팅과 핑은 그대로, 욕설은 사라지고, 비난 섞인 피드백은 **"용 먼저 치자"** 로 바뀌어 보임
4. 내가 "아 정글 ㅂㅅ 왜 안 와" 입력 → **"정글 탑 와줄 수 있어?"** 로 바뀌어 복사됨
5. 클라이언트 처리 내역 → 신고 문구 복사 → 고소장 PDF 다운로드
6. 백업: 실제 게임이 안 되면 **데모 재생 모드**(녹화한 화면 또는 jsonl 재생)로 같은 흐름을 시연

## 8. 성공 기준 (숫자로)

| 항목 | 목표 |
|---|---|
| 테스트셋 등급 분류 정확도 | 우리 테스트셋(`data/eval/`) 기준 측정 후 발표에 공개 |
| 우회 비속어 탐지 | 우회어 테스트 문장 50개 중 대부분 탐지 |
| 지연 시간 | 채팅이 뜬 뒤 오버레이 표시까지 **1.5초 이내** (리라이트는 3초 이내) |
| 데모 시나리오 | 대본 전 단계가 끊김 없이 진행 |

## 9. 하지 않는 것 (범위 밖)

- 게임 메모리 읽기, 드라이버, 패킷 조작, Vanguard 우회 → **절대 금지**
- 가상 키보드나 마우스 자동 입력으로 게임 조작 (ADR-0006)
- 롤 이외의 게임, 음성 채팅, 다국어
- 서버와 계정 시스템 (전부 로컬에서 동작)
- 실제 고소 접수 대행
